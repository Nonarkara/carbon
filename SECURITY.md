# Security and privacy / ความปลอดภัยและความเป็นส่วนตัว

The browser interface is static, with one read-only Cloudflare Pages Function at `/api/global` for public World feeds. There is no login, database, upload API, paid inference key or endpoint receiving project data. User files and input values stay in page memory. Refreshing loses them; exports are user-managed. Map providers receive tile requests and Cloudflare receives page requests. Choosing an Atmosphere layer sends tile requests (viewport and date) to NASA GIBS (gibs.earthdata.nasa.gov). A drawn box or imported boundary is summed locally against precomputed files; the geometry is not posted to the server. Panning to a boundary still discloses the displayed viewport through map-tile requests. The TGO T-VER registry block on the carbon map and the project boundary check use `public/data/tgo/tver-forestry.json`, a dated static file — no request is made to TGO from the browser. Never claim total offline operation.

หน้าเว็บเป็น static และมี Cloudflare Function อ่านข้อมูลโลกสาธารณะที่ /api/global ไม่มี API รับไฟล์โครงการหรือฐานข้อมูล ข้อมูลผู้ใช้เก็บในหน่วยความจำหน้าเว็บและหายเมื่อรีเฟรช ผู้ให้บริการแผนที่กับ Cloudflare ยังได้รับคำขอเครือข่ายตามปกติ เมื่อเลือกชั้นข้อมูลบรรยากาศ ระบบจะขอภาพจาก NASA GIBS ตามตำแหน่งแผนที่และวันที่ รูปขอบเขตคำนวณในเบราว์เซอร์และไม่ถูกอัปโหลด แต่การเลื่อนแผนที่ยังส่งคำขอภาพตามตำแหน่งที่แสดง

Input controls: UTF-8 decode, 2 MB cap, 10,000 CSV rows, finite numeric checks, bounded geometry/vertices, topology/overlap validation, escaped output, fixed source-link catalogue. File names and report references are rendered as text. CSV result export contains fixed field names, dates and numbers, not user-controlled spreadsheet formulas. JSON export is not a signed audit record.

Defence: self-hosted scripts/fonts, no inline script/eval, restrictive CSP, frame denial, MIME sniffing disabled and no privileged permissions. The development server exposes only public/. Third-party map requests are allowlisted. No external request is made from an imported URL.

Project maturity: pilot assessment tool. Security checks do not certify scientific accuracy, legal eligibility, data licences or official issuance. Contact the repository maintainer privately for suspected credential exposure; do not publish a token in an issue. General reproducible bugs can use GitHub Issues with synthetic inputs.

Public-feed boundary: `/api/global` calls four fixed upstream URLs in `server/world-data.js`; it accepts no user URL, project file or LLM prompt. Upstream requests have 8-second timeouts, numeric/schema/date validation, per-feed cache lifetimes and labelled fallback/missing states. It uses no paid inference credentials. Cloudflare service usage still follows the account plan. Browser refresh is bounded to five-minute intervals while visible, with concurrent refresh prevented.

Checks: `gitleaks git --redact`, `gitleaks dir public --redact`, `npm audit`, and `node scripts/release-smoke.mjs`. No automated scan proves absence of every secret or security flaw. The release audit records actual results, not a security certification.

GFW Forest Watch is an offline-ingested public snapshot. Its public browser fetch is same-origin `data/gfw/watch.json`; no GFW credentials or project boundaries are transmitted. Source API URLs contain only fixed public Thailand aggregation queries. GFW links open external sites when the user chooses them. Account membership alone does not configure API access. The legacy key helper stores a key only in ignored `.env`, mode 600, and does not print key suffixes or response bodies.
