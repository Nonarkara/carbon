# Standards scope check · 25 November 2026

Primary catalogue pages checked during the core research-table repair:

- [ISO14064-2:2019](https://www.iso.org/standard/66454.html): project quantification, monitoring and reporting; programme requirements remain additional. The catalogue still lists the2019 edition as published. A revision stage is not an adopted replacement.
- [ISO14067:2018](https://www.iso.org/standard/71206.html): product carbon-footprint quantification within LCA; offsetting is outside this standard's scope. The catalogue still lists the2018 edition as published.
- [GHGProtocol Corporate Standard](https://ghgprotocol.org/corporate-standard): organizational inventory accounting, distinct from project offset/credit accounting.

The TH/EN research comparison table retains complete edition labels and separates corporate, product, territorial, landscape and project accounts. A previous station layout implied a sequence between these alternatives and lost edition detail; it was restored to a comparison table. No ISO certification, new programme recognition, issuance entitlement or independent verification is asserted. This check inspected public descriptions, not licensed full-standard compliance or professional assurance.

A further primary-source check found a real edition gap: [ISO14068-1:2023](https://www.iso.org/standard/43279.html) is withdrawn; [ISO14068:2026](https://www.iso.org/standard/14068) is the September2026 replacement. The publisher describes a title/number change with the remaining content unchanged.
