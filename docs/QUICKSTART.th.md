## เปรียบเทียบจังหวัด · ประมาณ 1 นาที

1. [เปิดแผนที่](https://carbon.nonarkara.org/?lang=th) กด **ดูทั้ง 77 จังหวัด** ด้านบน
2. เลือกตัวเลขที่ต้องการดูในรายการ: การปล่อยจากฟอสซิล คาร์บอนสะสม หรือสุทธิของป่ารายปี แต่ละตัวตอบคนละคำถาม
3. กดชื่อจังหวัด หรือเลือกชื่อจากช่องจังหวัดด้านบน
4. อ่านผลด้านขวา บนโทรศัพท์ให้ดูแท็บ **คาร์บอน** สมการแสดงตัวเลขที่ใช้จริง ผลลัพธ์ หน่วย และปีของข้อมูล

**รู้ว่าทำสำเร็จเมื่อ:** ชื่อจังหวัดแสดงอยู่เหนือสมการ กด **ทั้งประเทศ** เพื่อกลับไปดูยอดประเทศ หากต้องการเปรียบเทียบจังหวัดอื่น ให้กด **ดูทั้ง 77 จังหวัด** อีกครั้ง

|ตัวเลขที่เห็น|หมายถึงอะไร|
|---|---|
|คาร์บอนสะสมในป่า · tCO₂e|คาร์บอนที่ป่าเก็บไว้ จากข้อมูลปี 2020 ไม่ใช่เครดิตรายปี|
|สุทธิของป่ารายปี · tCO₂e/ปี|การปล่อยลบการดูดซับ เฉลี่ยช่วง 2001–2025 ค่าติดลบหมายถึงดูดซับสุทธิ|
|CO₂ จากฟอสซิล · tCO₂/ปี|การปล่อยจากเชื้อเพลิงฟอสซิลในพื้นที่ จากข้อมูลปี 2024 ไม่ใช่การปล่อยของป่า|

## เลือกพื้นที่เอง · ประมาณ 1 นาที

1. เลื่อนและซูมแผนที่ไปยังพื้นที่ที่สนใจ **ก่อน** เริ่มเลือก
2. กด **↖ เลือกพื้นที่** แล้วคลิกหรือแตะมุมแรก ตามด้วยมุมตรงข้าม บนคอมพิวเตอร์จะกดค้างแล้วลากกรอบก็ได้
3. เมื่อปล่อยเมาส์หรือแตะจุดที่สอง ระบบคำนวณให้ทันที ไม่ต้องกดปุ่มคำนวณซ้ำสำหรับแผนที่
4. อ่านหัวข้อ **พื้นที่ที่เลือก** และสมการแทนค่า บนโทรศัพท์ระบบเปิดหน้าผลให้โดยอัตโนมัติ
5. หากต้องการเก็บผล ให้เลื่อนแผงผลลงไปที่ปุ่มส่งออก **JSON** หรือ **CSV** เก็บ JSON เพื่อให้มีรุ่นข้อมูลและขอบเขตพื้นที่ครบ

**รู้ว่าทำสำเร็จเมื่อ:** มีกรอบค้างอยู่บนแผนที่และหัวผลเป็น **พื้นที่ที่เลือก** ระหว่างเลือก กดปุ่มลูกศรซ้ำหรือ Escape เพื่อยกเลิก

**เครื่องหมาย — ก็มีความหมาย:** พื้นที่เล็กกว่าความละเอียดที่ให้บริการประมาณ 2.8 กม. จะงดแสดงค่า ส่วนข้อมูลไฟต้องประมาณ 28 กม. ลองขยายกรอบสำหรับการดูภาพรวม หากเป็นแปลงเล็กให้ใช้ข้อมูลภาคสนามในขั้นตอนโครงการ ข้อมูลการดูดซับ/ปล่อยของป่าในกรอบยังไม่ได้นำเข้า ขยายกรอบก็ไม่ทำให้ช่องนี้มีค่า และพื้นที่ที่ไม่มีเซลล์ข้อมูลบนบกของไทยจะไม่มีค่าประเมิน

## คำนวณโครงการ · ลองตัวอย่างก่อน

ขั้นตอนนี้แยกจากแผนที่ ระบบไม่นำค่าจังหวัดหรือกรอบที่วาดไปกรอกเป็นข้อมูลตรวจวัดโครงการ

<div class="task-flow"><span>ขอบเขต</span><b>→</b><span>ข้อมูลตรวจวัดพร้อมวันที่</span><b>→</b><span>คำนวณ</span><b>→</b><span>ส่งออกหลักฐาน</span></div>

1. เปิด **เครื่องมือโครงการ T-VER → พื้นที่โครงการ** บนโทรศัพท์ใช้แท็บพื้นที่โครงการด้านล่างได้
2. กดปุ่ม **ลองข้อมูลตัวอย่าง** ในหน้านี้ รอข้อความยืนยันขอบเขตปรากฏ ระบบใส่ขอบเขตและข้อมูลสมมติให้ ไม่ใช่โครงการที่จดทะเบียนจริง
3. เปิด **คำนวณ** แล้วกด **คำนวณผลประเมิน**
4. ตรวจว่าผลของช่วงเวลาคือ **218.86 tCO₂e** ตัวอย่างนี้ใช้มวลชีวภาพเหนือพื้นดินเพิ่มจาก 1,000 เป็น 1,100 ตัน: `100 × 1.27 × 0.47 × 44/12`
5. ส่งออกผลเป็น **JSON** และ **CSV** JSON เก็บข้อมูลนำเข้า ขอบเขต และสมมติฐาน ส่วน CSV เป็นตารางสรุป
6. กลับไปหน้าพื้นที่โครงการและกด **เริ่มใหม่** ก่อนใส่ข้อมูลจริง

**เตรียมอะไรสำหรับโครงการจริง:** ขอบเขต GeoJSON แบบ WGS84; วันที่ฐานหรือวันที่รับเครดิตครั้งล่าสุดและวันที่ติดตาม; มวลชีวภาพเหนือพื้นดินแห้งรวมทั้งพื้นที่สุทธิ หน่วยตัน ที่ทั้งสองวัน **หรือ** คาร์บอนต้นไม้รวมที่คำนวณเป็น tCO₂e แล้ว; แหล่งข้อมูลตรวจวัด; ร้อยละพื้นที่ไหม้และสถานะไฟเรือนยอด หากยังไม่ทราบสถานะไฟ ระบบจะไม่คำนวณ อย่าใส่ค่าตันต่อเฮกตาร์ในช่องที่ต้องการตันรวม

หากมีข้อมูลต้นไม้ ให้เปิด **หลักฐาน** ดาวน์โหลดแม่แบบ CSV ยืนยันว่าสมการเหมาะกับชนิดป่า อัปโหลดไฟล์ แล้วใช้ผลจากแปลงสำรวจ รูปแบบไฟล์และชนิดป่าที่รองรับอยู่ใน **รายละเอียดอ้างอิง** ด้านล่าง เมื่อเปลี่ยนขอบเขตหรือปัจจัย ผลที่เกี่ยวข้องจะถูกล้าง ต้องตรวจข้อมูลและคำนวณใหม่

**ส่งออกก่อนปิดแท็บ:** ข้อมูลอยู่ในหน่วยความจำเบราว์เซอร์ รีเฟรชหรือปิดแท็บเดิมแล้วข้อมูลจะหาย ผลลัพธ์เป็นค่าประเมินเพื่อทบทวน ไม่ใช่เครดิตที่ออกแล้ว

## Android และ iPhone · เพิ่มเว็บแอปบนหน้าจอโฮม

ใช้ระบบนี้ผ่านเว็บได้ทันที และเพิ่มไอคอนคาบอนนะบนหน้าจอโฮมเพื่อเปิดครั้งต่อไป

- **Android / Chrome:** เปิด [carbon.nonarkara.org](https://carbon.nonarkara.org/?lang=th) → เมนู **⋮** → **เพิ่มลงในหน้าจอหลัก** หรือ **ติดตั้งแอป** → ยืนยัน
- **iPhone / Safari:** เปิดเว็บไซต์ → **แชร์** (บางรูปแบบอยู่ในเมนูเพิ่มเติม) → **เพิ่มไปยังหน้าจอโฮม** → เปิด **เปิดเป็นเว็บแอป** หากมีตัวเลือก → **เพิ่ม**

**สำเร็จเมื่อ:** ไอคอนคาบอนนะปรากฏบนหน้าจอโฮม แตะเพื่อเปิดแผนที่ ต้องเชื่อมต่ออินเทอร์เน็ต และส่งออกข้อมูลโครงการก่อนปิดแอป ข้อมูลที่กรอกเก็บในหน่วยความจำของรอบใช้งาน

อ้างอิงขั้นตอน: [Apple Support](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios) · [Google Chrome Help](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=th)

## ชั้นข้อมูลและข้อมูลโลก

- **พืชพรรณ** แสดงแผนที่ป่าจาก JAXA **ละอองลอย** แสดงอนุภาคในบรรยากาศ ไม่ได้วัดเครดิตป่าไม้ บนคอมพิวเตอร์กด **ชั้นข้อมูลอื่น**เพื่อดูตัวเลือกอื่น บนโทรศัพท์ปุ่มละอองลอยเปิดแผงชั้นข้อมูลให้
- อ่านวันที่และคำอธิบายสีก่อนเปรียบเทียบ ภาพพื้นหลังใช้บอกตำแหน่ง ไม่ใช่หลักฐานวันที่ตรวจวัด
- ข้อมูลโลกอยู่ด้านซ้าย บนโทรศัพท์ใช้แท็บ **โลกและตลาด** กด **อัปเดต** เพื่อตรวจข้อมูลจากแคช อ่านวันที่สังเกตเสมอ: ความเข้มข้นรายวัน ข้อมูลไฟฟ้ารายครึ่งชั่วโมง และราคาประมูลรายไตรมาสไม่ใช่เวลาและหน่วยเดียวกัน
- **งานวิจัย** รวมคำอธิบาย ภาพประกอบ แหล่งข้อมูล และขอบเขตการอ้างอิง ISO เปิดแล้วข้อมูลโครงการยังอยู่

## ถ้าติดตรงไหน ให้ทำแบบนี้

|สิ่งที่เกิดขึ้น|ทำอะไรต่อ|
|---|---|
|บนโทรศัพท์ไม่เห็นแผนที่|กดแท็บ **แผนที่** ด้านล่าง|
|เลื่อนแผนที่ไม่ได้|อาจอยู่ในโหมดเลือกพื้นที่ กดลูกศรซ้ำหรือ Escape เพื่อยกเลิก|
|ค่าแสดง — หรือไม่มีข้อมูล|อ่านหมายเหตุ อาจเล็กกว่าความละเอียด อยู่นอกข้อมูลไทย หรือยังไม่มีชุดข้อมูลนั้น ไม่ใช่ศูนย์|
|นำเข้า GeoJSON ไม่ได้|ใช้พิกัด WGS84 ลองจิจูด/ละติจูด รูปปิดไม่ทับซ้อน ไฟล์ไม่เกิน 2 MB ดูรายละเอียดขอบเขตด้านล่าง|
|กดคำนวณแล้วไม่มีผล|อ่านข้อความใต้แบบฟอร์ม ตรวจวันที่ หน่วย แหล่งข้อมูล และสถานะไฟ อย่าเดาข้อมูลที่ยังไม่มีหลักฐาน|
|ผลเดิมหายไป|มีการเปลี่ยนข้อมูล ขอบเขต หรือปัจจัย ตรวจช่องกรอกแล้วคำนวณใหม่|
|ข้อมูลโลกขึ้นว่าสำรองหรือเก่า|ยังมีวันที่ของค่าที่เก็บไว้ ลองอัปเดตภายหลัง อย่านำเสนอว่าเป็นค่าปัจจุบัน|
|ต้องการเครดิตที่รับรองแล้ว|ดำเนินโครงการ ตรวจสอบ ติดตาม และทวนสอบตาม T-VER แอปนี้ออกเครดิตไม่ได้|

</section>
